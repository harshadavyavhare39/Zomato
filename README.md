# Zomato
Analyzed Zomato restaurant data using SQL to explore restaurant ratings, customer preferences, cuisines, pricing, and online ordering trends. Used queries, joins, aggregate functions, and grouping to identify insights and support data-driven decision-making.

1. **Data Collection:** Collected Zomato restaurant data.
2. **Data Cleaning:** Handled missing values and duplicate records.
3. **SQL Analysis:** Used SELECT, WHERE, GROUP BY, JOIN, and aggregate functions.
4. **Data Exploration:** Analyzed restaurant ratings, cuisines, pricing, and online ordering.
5. **Insights Generation:** Identified restaurant trends and customer preferences.
6. **Conclusion:** Generated meaningful insights to support data-driven decision-making.
